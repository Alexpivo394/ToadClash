# Изменения

## 1.1.0 — 2026-11-05

**Правила проверки** — `Alexpivo394.Revit.Clash.Rules`
- Условие на модель (файл): `PropertyKind.Model`, значение — ключ модели `ModelHeader.ModelKey`. Ключ модели элемента передаёт перегрузка `Condition.Matches(info, parameters, modelKey)`; наборы, предпросмотр и подсказки значений передают его сами.
- Остальные пакеты — без изменений, версия поднята вместе с правилами.

## 1.0.0 — 2026-11-03

Первый выпуск ядра поиска коллизий для Revit 2020–2027.

**Слепок модели** — `Alexpivo394.Revit.Clash.Geometry`
- Файлы `.tcg` (сетки элементов) и `.tcp` (параметры); оглавление `.tcg` читается без распаковки сеток.
- Повреждённый файл даёт `InvalidDataException` и не выделяет память по испорченным счётчикам.

**Правила проверки** — `Alexpivo394.Revit.Clash.Rules`
- Группы, наборы выбора, матрица проверок с допуском на клетку, исключения пар наборов.
- Числовые условия сравниваются по значению, общий параметр опознаётся по GUID.

**Поиск коллизий** — `Alexpivo394.Revit.Clash.Engine`
- Пересечение и вложение сеток с глубиной проникновения против допуска клетки.
- Повторный прогон по основе прошлого: неизменные пары не проверяются заново.
- Сопоставление пересозданных элементов по геометрии.
- Несовмещённые по общим координатам модели дают `ModelsNotAlignedException`.
- Результат не зависит от порядка моделей и числа потоков; версия алгоритма — `ClashEngine.AlgorithmVersion`.

**Картинки коллизий** — `Alexpivo394.Revit.Clash.Render`
- Сцена по оглавлениям слепков и PNG без видеокарты.

**Выгрузка из Revit** — `Alexpivo394.Revit.Clash.Revit` версии `{год}.1.0`
- Геометрия и параметры элементов 3D-вида в общих координатах; начало слепка — внутреннее начало документа.
- Ошибка Revit на одном элементе не обрывает выгрузку: элемент попадает в `ExtractResult.Skipped`.
