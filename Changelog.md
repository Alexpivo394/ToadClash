# Изменения

## 1.3.0 — 2026-11-11

**Поиск коллизий** — `Alexpivo394.Revit.Clash.Engine`
- Глубина там, где одно тело стоит в вырезе другого. Перегородка, заходящая в край отверстия пола на доли миллиметра, получала глубину, равную толщине пола, и становилась коллизией. Теперь после оценки по зоне считается местная глубина у самого места пересечения: нахлёст у края выреза — это его толщина, а тело, окружённое другим (труба в стене, штукатурка в стяжке), остаётся коллизией с прежней глубиной. Элемент из касающихся или вложенных тел считается одним телом.
- Дубликат — копия элемента на том же месте — остаётся коллизией, даже если элемент собран из тонких листов.
- `ClashEngine.AlgorithmVersion` — 2: прошлый прогон версии 1 не переиспользуется.
- Точная фаза примерно вдвое медленнее. На реальных моделях корпуса жилого дома ложных коллизий стало на треть меньше, настоящие не потерялись.

**Выгрузка из Revit** — `Alexpivo394.Revit.Clash.Revit`
- Источник света светильника (подкатегория «Источник света») не выгружается: шар вокруг лампы давал ложные коллизии с перекрытиями и трубами. Пакеты Revit — `{год}.1.3`.

**Слепок модели**, **Правила проверки**, **Картинки коллизий** — без изменений, версия поднята вместе с остальными.

## 1.2.1 — 2026-11-05

**Слепок модели** — `Alexpivo394.Revit.Clash.Geometry`
- Файл параметров `.tcp` читается в 10–12 раз экономнее по памяти: одинаковые значения параметров разных элементов — один общий экземпляр. На реальных моделях файл 7,4 МБ занимал 329 МБ памяти, теперь — 28 МБ. Формат не менялся.
- Нехватка памяти при чтении `.tcp` больше не выдаётся за `InvalidDataException` «Файл параметров повреждён»: исправный слепок отклонялся как испорченный.
- Остальные пакеты не менялись. Пакеты Revit остаются `{год}.1.2`, им подходит Geometry 1.2.1.

## 1.2.0 — 2026-11-05

**Правила проверки** — `Alexpivo394.Revit.Clash.Rules`
- Исключение набора со всей группой: `ClashConfiguration.GroupExclusions` из `SetGroupExclusion(SetId, GroupId)`. Действует как исключение набора с каждым набором группы, в том числе с добавленными позже; пара элементов снимается, только если исключены все сочетания их наборов. `ExcludedSetPairs()` раскрывает оба вида исключений в пары наборов.
- В JSON поле `groupExclusions` необязательно: конфигурация без него читается с пустым списком. Слияние черновиков и проверка конфигурации учитывают новые исключения.

**Поиск коллизий** — `Alexpivo394.Revit.Clash.Engine`
- Фильтр пар учитывает исключения набора с группой.

**Выгрузка из Revit** — `Alexpivo394.Revit.Clash.Revit`
- Выгрузка в Revit 2024 и новее больше не падает с `ArgumentException` при сборе категорий: с Revit 2024 базовый тип `BuiltInCategory` — `long`.


## 1.1.0 — 2026-11-05

**Правила проверки** — `Alexpivo394.Revit.Clash.Rules`
- Условие на модель (файл): `PropertyKind.Model`, значение — ключ модели `ModelHeader.ModelKey`. Ключ модели элемента передаёт перегрузка `Condition.Matches(info, parameters, modelKey)`; наборы, предпросмотр и подсказки значений передают его сами.
- Остальные пакеты — без изменений, версия поднята вместе с правилами.

## 1.0.0 — 2026-11-03

Первый выпуск ядра поиска коллизий для Revit 2020–2027.

**Слепок модели** — `Alexpivo394.Revit.Clash.Geometry`
- Файлы `.tcg` (сетки элементов) и `.tcp` (параметры); оглавление `.tcg` читается без распаковки сеток.
- Повреждённый файл даёт `InvalidDataException` и не выделяет память по испорченным счётчикам.

**Правила проверки** — `Alexpivo394.Revit.Clash.Rules`
- Группы, наборы выбора, матрица проверок с допуском на клетку, исключения пар наборов.
- Числовые условия сравниваются по значению, общий параметр опознаётся по GUID.

**Поиск коллизий** — `Alexpivo394.Revit.Clash.Engine`
- Пересечение и вложение сеток с глубиной проникновения против допуска клетки.
- Повторный прогон по основе прошлого: неизменные пары не проверяются заново.
- Сопоставление пересозданных элементов по геометрии.
- Несовмещённые по общим координатам модели дают `ModelsNotAlignedException`.
- Результат не зависит от порядка моделей и числа потоков; версия алгоритма — `ClashEngine.AlgorithmVersion`.

**Картинки коллизий** — `Alexpivo394.Revit.Clash.Render`
- Сцена по оглавлениям слепков и PNG без видеокарты.

**Выгрузка из Revit** — `Alexpivo394.Revit.Clash.Revit` версии `{год}.1.0`
- Геометрия и параметры элементов 3D-вида в общих координатах; начало слепка — внутреннее начало документа.
- Ошибка Revit на одном элементе не обрывает выгрузку: элемент попадает в `ExtractResult.Skipped`.
