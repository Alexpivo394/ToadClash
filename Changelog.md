# Изменения

## 1.0.0 — не выпущено

Первый публичный выпуск ядра поиска коллизий для Revit 2020–2027.

- `Alexpivo394.Revit.Clash.Geometry` — формат слепка модели `.tcg`/`.tcp`: сетки элементов, оглавление без распаковки сеток, параметры. Повреждённые файлы дают `InvalidDataException` без больших выделений памяти.
- `Alexpivo394.Revit.Clash.Rules` — группы, наборы выбора, матрица проверок с допусками, исключения пар наборов. Числовые условия сравниваются по значению, общий параметр ищется только по GUID.
- `Alexpivo394.Revit.Clash.Engine` — поиск пересечений сеток по правилам, инкрементальный прогон по основе прошлого прогона, сопоставление пересозданных элементов. Модели части, не совмещённые по общим координатам, дают `ModelsNotAlignedException`. Результат не зависит от порядка моделей и числа потоков. Версия алгоритма — `ClashEngine.AlgorithmVersion`.
- `Alexpivo394.Revit.Clash.Render` — картинки коллизий.
- `Alexpivo394.Revit.Clash.Revit.{год}` — выгрузка геометрии и параметров 3D-вида в общих координатах. Начало координат слепка — внутреннее начало документа. Сбой одного элемента не обрывает выгрузку: элемент попадает в отчёт `ExtractResult.Skipped`.
